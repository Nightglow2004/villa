# Property Listing Website

A simple property listing webpage that displays available properties with a contact page. The design is visually appealing but not responsive, optimized only for large screens.

## Technologies Used
- HTML
- CSS
- Tailwind CSS
- JavaScript

## Features
- Displays a list of properties with images and details
- Includes a contact page for inquiries
- Uses Tailwind CSS for styling
- Smooth UI with JavaScript enhancements

## Limitations
- Not responsive; best viewed on large screens

## Usage
- Navigate through the listed properties
- Visit the contact page for inquiries

## Future Improvements
- Make the design responsive for all screen sizes
- Improve accessibility and user experience
